# fMRIStatisticalAnalysis_SPM
fMRI-based investigation on the matter of Repetition Suppression
Abstract
Applied SPM preprocessing, GLM-based beta-weight extraction, ROI masking, and statistical hypothesis testing to study neural repetition suppression. 
Overview
This project investigates Repetition Suppression (RS) in the brain’s Fusiform Face Area (FFA) and Para-hippocampal Place Area (PPA), examining how neural responses differ between matching and non-matching face and non-face stimuli. Functional MRI data were preprocessed in SPM, followed by first-level General Linear Model (GLM) analysis to construct design matrices and extract condition-specific beta weights from BOLD/HRF responses.
Region-of-interest analyses were conducted using separate FFA and PPA masks, with paired-sample t-tests used to evaluate differences between matching and non-matching conditions. The statistical results supported the presence of Repetition Suppression and indicated a stronger effect in the FFA than in the PPA, providing evidence for differences in repetition-related neural responses across the two brain regions.
